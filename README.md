# ChatWorkBridge

把 **ChatGPT 网页聊天**和 **WorkBuddy 国际版桌面**接起来：GPT 派工，WorkBuddy 回复，结果自动回到同一 GPT 聊天，继续审核、返工和验收。

**当前源码版本：0.4.0-preview.4，Windows x64 预览版。** 首次启动自动检测软件，未找到时可点“浏览”选择；不需要提前准备本机配置。日常模式沿用既有 MCP 和 Skill；完整闭环仍待新的真实账号验收。

## 下载和启动

1. 从 [Release 列表](https://github.com/mmiaommiaom/ChatWorkBridge/releases) 选择已经发布的版本，下载安装 EXE，或下载 portable ZIP 解压。源码版本不表示对应安装包已经发布。
2. 选择 **D、E、F 等非 C 盘**中的安装目录。运行数据默认保存在项目所在盘，不能安装到 C 盘或网络共享。
3. 双击 **START.vbs**。浏览器打开本机设置向导；默认端口 18694，已占用时自动选择空闲端口，再次打开复用同一安装的页面。
4. 按向导完成：自动检测或浏览选择软件 → 选择 WorkBuddy 模式 → 保存配置 → 打开两边 → 自行登录 → 连接会话 → 打开协作台。

发行包内置 Node.js，无需自行安装 Node 或运行 npm。**Chrome 和 WorkBuddy 国际版需要自己安装**，并使用自己的账号。详细步骤与排错见 [安装说明](docs/SETUP.md)。

程序可以安装或解压在任意可写的非 C 盘本地目录，不需要固定 D/E 盘路径。数据库、日志和独立资料默认放在程序旁；一起移动目录时，先结束任务并关闭受管应用，移动后重新连接。程序目录内的软件路径按相对位置保存，外部已安装软件按本机位置检测，不随发行包附带个人路径。

若双击后没有打开页面，运行 **START.cmd** 查看错误与日志。本项目目前未签名；遇到 SmartScreen 或企业策略拦截应停止，核对本仓库 Release 资产与 SHA256SUMS，或选择可审计源码，不应绕过系统或企业拦截。

## 已有能力

- GPT → WorkBuddy → GPT 自动往返，支持返工、验收和有限轮数。
- 同一任务保留在同一 GPT 聊天；新任务复用受管标签页。
- SQLite 保存任务与发送状态；遇到不确定结果时停止，避免重复执行。
- 本地协作台支持开始、当前回复结束后暂停、继续正常暂停的任务。
- 将实际取得的 GPT 回复附件转交 WorkBuddy。WorkBuddy 的结果目前以文字返回 GPT，尚未实现自动回传它生成的图片或文件。
- 无推理初始化只创建或核验会话，不发送模型消息；重复连接不会重建会话。

此前开发环境已实测三轮文字闭环、TXT/PNG，以及专用测试中的文件读写、固定 Node 命令和 Chrome 测试页操作。**本预览发行版的安装向导、跨盘运行和完整正常模式尚未完成新的真实账号验收。** CI 仅验证依赖、语法与 Windows 离线测试，不登录或调用模型。详见 [功能状态](docs/STATUS.md)。

## 日常配置与权限

独立模式不包含日常 WorkBuddy 的 MCP、Skill 和会话，默认任务仍限文字推理和附带参考附件。

在向导选择日常模式，并明确授权已有 WorkBuddy 资料目录，即可沿用现有 MCP、Skill 和普通权限。先保存工作并退出原有实例，再按 [日常接入说明](docs/SETUP.md#高级正常模式) 操作。完整真实接入仍待验收，不代表已经能够一键操作任意软件。工作器权限由 WorkBuddy 配置决定，本项目没有实现 Windows 系统级沙箱。Chrome 使用本机已安装程序和本项目独立资料目录，需要在该窗口单独登录。

## 模型与附件边界

默认自主调用白名单为 hy3、step-5-preview、deepseek-v4.1-flash，支持别名 deepseek-4.1flash。其他模型、自动模型与默认模型别名会被拦截，需使用者另外批准。

这是使用者指定的免费模型策略，**不是价格、余额或永久免费保证**。DeepSeek 与 HY3 曾实际成功；Step 的一次测试返回服务端 500。剩余额度与重置时间未知，真实额度耗尽的自动切换仍未验收；模拟错误测试已覆盖额度耗尽、限流和服务错误。出现正文、工具执行或不确定结果时不自动重做。

附件仅处理实际取得、大小和内容检查通过的文件。只有文件名而无下载地址、也无已知本地原文件的卡片暂不能取回。PDF、Word 等未逐种实测解析。
