## 执行与恢复规则

发送动作前先持久化记录。只有明确失败、没有正文或工具执行，并且远端会话确认空闲时，才允许切换获准模型重试。通信中断、超时和页面消失均不能单独证明远端没有执行。

初始化与真正派工分别记录。“会话已连接”不表示已经调用模型，也不表示余额与模型服务可用。初始化出现不确定状态时，不重新生成 ID 并重复创建；保留原 ID 核验。

正常模式要求使用者明确授权已有资料目录，程序不静默终止日常会话，不复制凭据，不加入绕过权限检查选项。应用自身必要的系统运行记录另需明确授权；重定向数据目录不构成系统级写入保证。

应用升级、重新登录、更换账号或迁移版本后，应重新核对结果归属和附件读取。源码离线测试与发行打包检查不能代替真实账号和应用的验收。
