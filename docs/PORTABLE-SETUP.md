# 无预配置与便携启动

0.4.0-preview.3 的发行包不包含开发者的 local.json、程序路径、日常资料、账号或数据库。使用者不用提前建立特定 D/E 盘文件夹。

1. 安装或解压到自己有写权限的非 C 盘本地目录；支持中文和空格目录。
2. 打开 START.vbs。向导的默认端口冲突会自动避让；同一安装再次打开复用原服务。
3. 自动检测 Chrome 和 WorkBuddy；未找到时点“浏览”选择真实 EXE。系统注册表、环境 PATH、常见位置以及程序旁 apps 目录均为有限检测来源，不扫描全盘或读取账号数据库内容。
4. 独立模式的浏览器、WorkBuddy 资料、缓存和工作区自动创建在程序旁；日常模式检测已有资料，可选用户资料目录或其含 workbuddy.db 的配置子目录。不会把一个新建文档文件夹伪装成已有 WorkBuddy 配置。
5. 核对并保存模式与授权，再打开应用、登录和连接。路径选择与自动检测本身不保存授权、不发送模型消息。

## 移动目录

默认数据跟随程序目录。程序内部的软件路径以 ./ 相对位置保存；外部已安装软件按其本机位置保存，不猜测所有电脑都安装在同一处。

移动前结束任务并关闭受管应用。整体移动后重新打开、连接。已空闲完成的旧绑定在本机保留备份，再为新工作区创建专用会话；不修改远端旧会话，不发送任务。未完成、不确定任务或正在运行的锁会阻止重新连接。不同电脑需要使用者自己的软件和登录，不随包迁移凭据。

## 选择器实现

已比较 FileDialog、node-fs-dialogs、node-windows-ui 等开源方案。为避免额外原生二进制、编译依赖或额外注册表输出，复用当前启动器已使用的 Windows Script Host，并通过微软记录的 [Shell.BrowseForFolder](https://learn.microsoft.com/en-us/windows/win32/shell/shell-browseforfolder) 打开系统选择窗口。代码在 scripts/select-path.vbs 和 src/path-picker.mjs。

只有点击浏览才运行固定脚本，选择结果作为路径数据返回，服务端再次核对文件头或资料目录元数据。不调用 PowerShell、不改执行策略、不自动执行所选 EXE。系统禁用 Windows Script Host 时可直接填写路径。

## 本轮验证

95 项离线测试通过；新增合成测试覆盖：无 local.json 的自动检测、便携目录内相对路径、中文和空格目录迁移、固定选择器参数与权限接口、会话搬迁不重发。Windows Shell COM 组件可加载。系统选择窗口中的用户手动点击与跨电脑真实登录不属于这些离线测试的证明范围。

仍保留非 C 盘数据要求，未扩大到系统级沙箱。实际软件操作与账号、WorkBuddy 版本和其 MCP/Skill 配置有关。
