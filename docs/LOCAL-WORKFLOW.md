# 本地协作链路（2026-10-27）

本轮只更新本地源码和现用本地目录，未打包、未推送、未发布。已有发行包不因此获得这些修复。

## 使用

打开原本地协作台地址。提交目标后，GPT 先制定总体验收标准和必需/可选能力，再读取日常 WorkBuddy 当前工作区的 MCP、Skill 等状态。缺少必需能力时，“需要你处理”面板列出用途、状态和操作步骤，暂不派工。请在 WorkBuddy 或对应软件中处理，然后点击“已完成，重新检查”；点击按钮本身不会把状态伪装成已连接。

在面板输入回复，点击“回复 GPT”。回复按任务和客户端消息 ID 保存；刷新、重复请求不会重复发送。执行中的补充消息在下一次安全边界送进原 GPT 聊天。“暂停后续派工”等待当前回复完成，不发送远端取消。保留“查看原 GPT 聊天”链接。

总体验收标准首次冻结，步骤说明不会替换总标准。GPT 持续审核和返工，不限制三轮；所有条件均有证据并通过 GPT 审核后结束。变更总标准须通过单独的明确批准。专家、未知模型或未知费用不能因一般“继续”消息获得授权。

## 附件和文件

- GPT 图片和代码块按同一逻辑回复关联，兼容生成图片拥有单独消息 ID 的页面结构。实际文件下载后验证类型、大小、哈希，再同时向 WorkBuddy 发送像素内容和本地路径。
- 必需参考图缺失、文件改变或附件传输失败会阻止派工，不允许退回文字猜测。
- WorkBuddy 最终回复通过 `bridge-artifacts` 或仅包含 `files` 的 JSON 清单声明实际产物。只接收固定任务目录内的普通文件；拒绝路径越界、链接和修改后的文件。
- 支持上传的图片、文本和文档会上传到原 GPT 聊天，检查上传预览就绪后才发送。单附件上限 10 MiB。Blender 原生工程等不支持格式或大文件只保存本地存在性和大小证据，明确标记未上传，不能视为 GPT 已审阅文件内容。
- 新工作区按日期和目标关键词命名，以任务 ID、会话 ID 和目录关联。修改显示名称不会改变 ID；移动实际目录会要求重新核对。旧目录不移动。

## 持久化和恢复

SQLite 保存任务、原始派工、发送状态、用户回复、能力报告及审核记录。发送前先写入 outbox。持续的 MessagePort 连接独立于单次等待；等待超时不关闭远端端口，也不自动重发派工。

WorkBuddy 等待权限或输入时，协作台提示到原任务处理，并继续监听。结果按原请求 ID 保存再回传。连接恢复先核对持久化记录、远端缓存或同一 GPT 聊天历史；证据不足保持待核验。旧失败任务缺少完整请求证据时需人工核对，不能自动重做。

## 权限与实际边界

直接派工模型保持用户批准的三个免费模型白名单。价格、余额和剩余额度未知；额度故障分类及安全切换有故障注入测试，不能冒充真实账号已耗尽额度验证。只有远端确认空闲、没有正文和工具执行且属于明确可重试服务故障时，才允许安全切换模型。

日常模式沿用现有全局 MCP/Skill 与普通工具权限；其他工程目录专用的 Skill 不会自动复制。能力检查不自动安装、启用、信任或登录。专家自动调用及完整模型费用链尚无可靠证明，标为待确认并暂停；可由 GPT 改用已验证方案。

这不是 Windows 系统级隔离：正常 WorkBuddy 的工具权限依赖其自身配置。桥接验证附件和任务关联，并要求不写 C 盘、不隐藏执行 PowerShell，但不能把这些提示词说成操作系统访问控制。

网页选择器和 WorkBuddy 本地接口可能随应用升级变化；无法确认时停止，保留记录。实际断网、系统强制重启、跨电脑迁移和全部文档格式解析仍需各自实测。

## 多个保存工作（本地更新）

协作台顶部“我的工作”保存所有任务，可搜索、改名、归档并重新打开。每个工作关联自己的 GPT 聊天、WorkBuddy 会话和目录；改显示名称不移动文件。新建工作不会覆盖旧聊天。归档仅隐藏列表项，勾选“显示归档工作”可找回。

一次执行一个工作。切换查看不会启动或中断任务；要执行另一个工作，先暂停当前工作并等待本轮结束，再打开目标工作点击“继续此任务”。其他暂停或等待用户的工作可以同时保存；存在待核验的发送时，先核验才能派工。

已经验收完成的工作可在回复框输入后续目标，点击“以此目标继续原工作”。程序沿用原聊天、会话及目录，为新阶段制定新的验收标准，并保留旧阶段标准、结果和完整对话。普通刷新、重复点击不会重复建立阶段。未完成的工作仍按原验收标准继续。

关闭协作台后，下次从原 START.cmd 打开即可找回；浏览器和 WorkBuddy 重启后需要按向导重新连接。找不到原会话、目录移动或历史不一致时暂停核验，不自动重建或重做。完整对话按页读取，记录保存在本机 data/bridge.sqlite，删除本地目录会丢失记录，请保留目录或自行备份。

## 删除工作

工作列表的“删除”需要明确确认。删除本地数据库中的该工作记录、该任务附件及已核对归属的专属工作目录和产物，并压缩数据库。不可撤销；运行中或结果待核验的工作不能删除。不会删除 GPT 网页或 WorkBuddy 原聊天，也不清理既有备份。目录归属不明确或含链接时拒绝删除。
